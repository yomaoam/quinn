# quinn.ie

Landing page for quinn.ie — a static one-pager linking to the sites that
live on its subdomains (Fógra, Mortar, Áinle, The Cave).

Trail-map theme built around trail running in the Tatras: paper texture,
topographic contours, and the four projects laid out as waypoints along a route.

Hosted on GitHub Pages. No build step: `index.html` is the whole site, with
`assets/` holding the hero photograph, card illustrations, paper tile and
generated contour SVG. `CNAME` pins the custom domain; `.nojekyll` skips
Jekyll processing. Type is Anton / Oswald / Lora / Caveat via Google Fonts.
